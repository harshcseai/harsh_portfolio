## Local Setup

Since this is a static website, you can run it without any package installation.

### Option 1: Open directly

Open `index.html` in your browser.

### Option 2: Run locally via Python

```bash
cd harsh_portfolio
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
