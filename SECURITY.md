# Security policy

This is a static GitHub Pages portfolio: it does not collect user accounts, accept payments, or process form submissions. Please report a reproducible security issue privately at harshgupta7367@gmail.com rather than publishing it first.

The site uses local assets for technology marks, `rel="noreferrer"` on external project links, a `security.txt` contact, and GitHub Pages' HTTPS support when the custom domain is configured with **Enforce HTTPS** enabled.
